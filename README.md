# Tugas2-P.web

Buatlah sebuah website profil sekolah asal. Website harus terdiri dari minimal 3 halaman yang saling terhubung. Dokumentasi sertakan screenshot website sekolah asal beserta linknya.

📋 Kebutuhan Halaman
1️⃣ index.html

Header berisi:

Nama Sekolah

Logo (gunakan tag <img>)

Navigation menu (Home, Jurusan, Kontak)

Section:

Sambutan Kepala Sekolah

Visi & Misi 

Footer:

Copyright

2️⃣ jurusan.html

Daftar jurusan menggunakan:
```
<h2>

<p>

<ul>
```
Buat tabel jumlah siswa tiap jurusan menggunakan <table>

3️⃣ kontak.html

Form kontak menggunakan:
```
<form>

<input type="text">

<input type="email">

<textarea>

<button>
```
